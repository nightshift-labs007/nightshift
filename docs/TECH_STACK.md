# Nightshift — Tech Stack & Protocol Integrations

Status as of 12 Oct 2026. For architecture and formulas see [TECHNICAL.md](TECHNICAL.md); for go-live steps see [TESTNET.md](TESTNET.md).

---

## At a glance

| Layer | Stack |
|---|---|
| App | Next.js 15 (App Router), React 19, TypeScript 5.9 |
| Hosting | Vercel (Hobby), Vercel Cron, cron-job.org for 5-min keeper |
| EVM | Solidity 0.8.26 (solc), Hardhat 2 (local chain), viem 2, Base Sepolia |
| Wallets | EIP-6963 browser wallets, WalletConnect v2 (Reown) |
| Lending model | Morpho Blue (LLTV tiers, LIF liquidation, `IOracle` adapter) |
| Zero-knowledge | Circom 2.1.6, circomlib, Groth16 / BN254 via snarkjs 0.7.6 |
| Ledger | Algorand TestNet via algosdk 3 + AlgoNode |
| AI | Claude (Anthropic SDK) news agent |
| Formal verification | Lean 4 + Mathlib, proofs generated by Harmonic Aristotle |
| Yield | Sentora PRIME vault (ERC-4626) read via DefiLlama + Ethereum RPC |
| Data | Yahoo Finance (charts + RSS), alternative.me Fear & Greed |

## Protocol integrations

| Protocol | What we use it for | How it's wired | Code | Status |
|---|---|---|---|---|
| **Morpho Blue** | Lending rules for the Vault: LLTV 77% (SPY/QQQ/GLD) and 62.5% (IBIT), liquidation incentive `LIF = min(1.15, 1/(0.3·LLTV + 0.7))` | `MorphoOracleAdapter` exposes Nightshift prices in Morpho's `IOracle` shape (`price()` scaled 1e36); Vault contract and paper engine follow Morpho Blue math | `contracts/NightshiftOracle.sol`, `contracts/NightshiftVault.sol`, `lib/paper.ts` | Contracts built and tested (15/15 local); paper mode live |
| **Base Sepolia** | Testnet for Oracle, Vault, Guardian, ZK verifier, test tokens | viem client; deploy script writes `lib/chain/deployment.json`; keeper pushes prices on >0.1% move or every 30 min | `lib/chain/*`, `scripts/deploy-contracts.mjs`, `/api/keeper`, `/api/drip`, `/api/chain` | Ready to deploy (`deployed: false` until funded) |
| **Robinhood Chain** | Target network for tokenized ETF / Stock Tokens | Product target; Base Sepolia stands in until Morpho availability is confirmed | — | Planned |
| **Algorand** | Tamper-evident record of each pre-open prediction, plus the formal-verification manifest hash | 0-ALGO self-payment with note `nightshift:v1:` + SHA-256 payload; read back from the indexer | `lib/algorand.ts`, `/api/commit`, `/api/ledger`, `scripts/formal.mjs anchor` | Built; on once `ALGORAND_MNEMONIC` is set |
| **Groth16 (circom/snarkjs)** | Cloak: prove a hidden loan is solvent at the Oracle price | 918-constraint circuit, Poseidon commitment; browser proving, server verify + on-chain Solidity verifier | `zk/solvency.circom`, `public/zk/*`, `/api/zk/verify`, `contracts/SolvencyVerifier.sol` | Live |
| **Sentora** | Earn panel: show PRIME (PYUSD, Ethereum) vault APY, TVL, share price | DefiLlama yields API for history; optional on-chain `convertToAssets` / `totalAssets` read of the ERC-4626 vault; UTM deep link to deposit | `lib/earn/sentora.ts`, `/api/earn/sentora`, `components/Earn.tsx` | Phase 1 (read-only); Nightshift never touches funds |
| **Firelight** | Cover badge on the Sentora vault | Feature flag `SENTORA_FIRELIGHT_COVER` | `lib/earn/sentora.ts` | Off until Sentora confirms |
| **Harmonic Aristotle** | Machine-generated Lean proofs of Vault, Guardian, Oracle and Cloak math | `formal:prove` sends a module to Aristotle; result accepted only if statements are unchanged; CI re-checks with Lean's kernel and fails on `sorry` / extra axioms | `formal/`, `scripts/formal.mjs`, `.github/workflows/formal.yml` | Live in CI |
| **Anthropic Claude** | Fifth Oracle signal: scores latest headlines per ETF (−1…+1) | `@anthropic-ai/sdk`, structured output, cached hourly; default model `claude-opus-5-5` (`NEWS_MODEL` overrides) | `lib/news.ts` | Optional (`ANTHROPIC_API_KEY`) |
| **WalletConnect / Reown** | Mobile wallets via QR | `@walletconnect/ethereum-provider`; browser wallets discovered via EIP-6963 | `lib/wallet.tsx`, `components/WalletButton.tsx` | Optional (`NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID`) |

Referenced but not integrated: **Aave** (planned venue), **Zcash** (same proof system family), **Monero** (privacy reference).

## Tooling & ops

- **Scripts:** `contracts:compile`, `contracts:deploy`, `chain:local`, `zk:build`, `algo:account`, `formal:prove | check | test | anchor`
- **Crons (`vercel.json`):** `/api/commit` weekdays 12:00 UTC (Algorand stamp), `/api/keeper` daily 12:30 UTC (fallback; cron-job.org runs it every 5 min)
- **CI:** GitHub Actions `formal-verification` — Lean build, axiom audit, Lean test vectors replayed against the real contracts on Hardhat, manifest build, Algorand anchor on `main`
- **Lean:** toolchain `v4.28.0`, Mathlib `v4.28.0` (pinned to what Aristotle supports)
