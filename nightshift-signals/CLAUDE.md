# Nightshift Signals

Every headline becomes an ETF trade in 60 seconds, graded in public at the market open.

News lands while US exchanges are closed (17.5 h every weekday, plus weekends). Nightshift Signals ingests headlines, dedupes and triages them, maps severity 3+ events to a basket of 2–4 sector ETF Stock Tokens on Robinhood Chain, sizes each leg against real pool depth, hashes the basket onchain, and pushes it to users with one-tap deep links into their own wallet. At 9:45 ET every basket is graded against executable entry quotes and published on a public scorecard, misses included. The graded record is the product; the AI is the easy part.

Full spec: `docs/BUILD.md` (section numbers match the blueprint deck). Read the sections named for the current session, then plan before coding.

## Non-negotiables

1. **Commit before you show.** The publisher refuses to fan out a basket without a confirmed commit tx. If the chain is congested for more than 20 s, publish with a `pending` flag and the signed hash, then attach the tx when it lands.
2. **Grade on executable prices.** Entries are the stored executable quote with slippage, never oracle mids or a recomputed price.
3. **Nobody goes first.** No code path delivers a basket to any subset of users before the public feed. No paid early access, ever.
4. **No custody.** We never hold user funds or keys. The commit key holds gas only.
5. **US geofence before any trade link renders.** Stock Tokens are not available to US persons.
6. "Information, not advice" labels in product. Store headline, summary and link only, never full article text.

## Architecture

Four deployables plus infra. Services communicate **only through events** on Redis Streams, never by calling each other.

- `apps/web` Next.js App Router PWA (Vercel)
- `apps/api` Hono REST `/v1` + WebSocket `/ws`
- `apps/worker` one Node process running BullMQ queues: ingest, dedupe, triage, mapper, sizer, committer, publisher, grader, plus the morning brief and lock-screen live updates
- `apps/mobile` Expo (expo-router) app for lock-screen tracking: iOS Live Activity (`modules/live-activity` native module + `targets/live-activity` widget via @bacons/apple-targets), Android ongoing notification fed by data-only Expo pushes. `ios/` and `android/` are generated by `expo prebuild`, never committed.
- `packages/core` Zod schemas, event envelope, taxonomy.yaml (source of truth for every type)
- `packages/db` Drizzle schema and migrations · `packages/ai` prompts and tool schemas
- `packages/chain` NightshiftSignalsLedger contract, viem · `packages/adapters` NewsSource, PriceSource, QuoteSource, Notifier
- `scripts/` replay and grade
- Postgres + pgvector, Redis (Streams, BullMQ, price cache, rate limits)

## Conventions

- TypeScript strict. Every schema is defined once in `packages/core` as Zod; types and JSON Schema are derived from it.
- IDs are ULIDs (baskets: `bkt_YYYYMMDD_HHMM_suffix`). Every object has a stable ID.
- Time: UTC in storage; `America/New_York` for market schedules and crons (never hard-code UTC offsets; DST moves).
- Money, prices and returns: decimal strings in Zod, `numeric(38,18)` in Postgres. Never floats. Weights and confidence are bounded numbers.
- Enums are defined once in `packages/core/src/enums.ts`; Drizzle pgEnums are built from them. `packages/db/src/mappers.ts` converts core objects to rows and back (and re-validates).
- DB invariants are also enforced in Postgres: published/graded baskets need a hash, leg weight ≤ 0.5, one grade per basket, `deliveries` append-only.
- Events: envelope `{id, type, version, occurred_at, producer, correlation_id, payload}`; immutable, versioned (add fields, never rename). Every consumer is idempotent. Failures go to a dead-letter stream, retried with backoff up to 3 times.
- Canonical JSON for hashing (`basketCanonicalJson` in core): keys sorted, no whitespace, every number a string; money padded to 18 decimals, weights 6, confidence 4. Raw floats throw. Only pre-publish fields are hashed.
- Models: `claude-haiku-5-5` (triage), `claude-sonnet-5-5` (mapping). JSON comes from structured outputs (`output_config.format`), not forced tool calls (current models reject forced `tool_choice`); leg tickers are an enum built at runtime from the eligible registry. Sonnet calls use `fallbacks: "default"` for refusals. Bump `TRIAGE_PROMPT_VERSION`/`MAP_PROMPT_VERSION` in `packages/ai/src/prompts.ts` on any prompt change and run `pnpm replay` before shipping it.
- Stages are functions over `Deps` (`apps/worker/src/deps.ts`); vendors sit behind interfaces in `packages/adapters`. Tests use PGlite + `InMemoryBus` + `SimMarket` + `FakeJsonModel` via `apps/worker/src/testing.ts`.
- Only baskets with `published_at` are ever served by the API (`apps/api/src/views.ts`).
- Internal packages export TypeScript source directly; relative imports are extensionless (Turbopack can't map `.js` to `.ts`). Only `@nightshift-signals/db` imports drizzle-orm; other packages use its re-exported helpers so there is one instance.
- Chart colors: `--beat` (blue) and `--miss` (orange), validated for color-vision deficiency; red/green failed. Series use `--s1..--s4` in fixed order. Results always carry ▲/▼ and a word.
- UI text lives in `apps/web/messages/{en,hi,es}.json` (next-intl, locale from the `fp.lang` cookie, no URL prefix). Every key exists in all three. Thesis translations (`thesis_i18n`) are added at publish and are never hashed.
- Push preferences decide which alerts a subscriber gets, never when: one alert goes to every matching subscriber in the same fan-out.
- Follow or fade locks 30 minutes after publish; the crowd is graded like the AI. The paper league has no money and no prizes.
- A category with ≤ 50% hit rate four straight weeks is auto-disabled (`category_overrides`); re-enabling is a human decision.
- Why-chains (2–4 steps, ≤ 80 chars each) are hashed only when non-empty, so older basket hashes still verify. `why_chain_i18n` is added at publish, never hashed.
- Live Activity `ContentState` is defined three times and must match: `packages/adapters/src/notify/live-activity.ts` (LiveState), `apps/mobile/lib/live-state.ts`, and both `NightshiftSignalsAttributes.swift` copies (module + widget target). Change all four together.
- When a vendor detail is unknown (Robinhood Chain RPC URL, chain id, Uniswap addresses, Stock Token list, deep-link formats), stop and ask. Never guess.

## Commands

```
pnpm install
pnpm dev:local        # no Docker or keys: API + pipeline in one process (PGlite in .data/, simulated market,
                      # simulated ledger, scripted headlines every 2 min) + web :3000. Everything labeled simulated.
pnpm db:up            # docker compose: Postgres (pgvector) + Redis
pnpm dev              # web :3000, api :8787, worker (needs REDIS_URL; NIGHTSHIFT_SIGNALS_MODE=live needs every var in LIVE_REQUIRED)
pnpm test             # vitest, all packages (db tests run on in-memory PGlite + pgvector, no Docker needed)
pnpm typecheck
pnpm db:generate      # drizzle-kit: new migration from packages/db/src/schema.ts
pnpm db:migrate       # apply migrations to DATABASE_URL
pnpm schemas:json     # regenerate packages/core/json-schema/*.json
pnpm replay --date YYYY-MM-DD [--offline]   # replay a night through current prompts, isolated; report in scripts/replays/
pnpm grade --date YYYY-MM-DD [--post]        # grade baskets due 9:45 ET that day (idempotent)
pnpm recompute --csv <file|url> [--api url]  # independently recompute every grade and verify hashes
pnpm eval --from D --to D [--offline] [--label L]       # eval harness: replay a date range, pooled scorecard → scripts/evals/
pnpm eval:compare --baseline a.json --candidate b.json  # ship gate: exit 0 only if candidate hit rate beats baseline (≥30 graded each)
pnpm backfill:gdelt --from D --to D [--query Q]         # headline history for analogs/evals (prices for those nights need a vendor)
pnpm telegram:setup   # register the bot webhook and the Mini App menu button (needs TELEGRAM_* and API_PUBLIC_URL)
pnpm --filter @nightshift-signals/mobile start       # Expo dev server; Live Activities need a dev build (`expo run:ios`), not Expo Go
pnpm --filter @nightshift-signals/mobile prebuild    # generate ios/ + android/ (widget target included)
```

Environment variable names live in `.env.example`. Never commit values.

## Before going live (unconfirmed vendor details; fill from official docs, never guess)

- Robinhood Chain RPC URL and chain id; deploy `packages/chain/contracts/NightshiftSignalsLedger.sol` (testnet first) with a gas-only committer key.
- Which Uniswap version is on Robinhood Chain (the quote adapter is v3 QuoterV2; v4 needs a new adapter), quoter address, USDG address/decimals, Uniswap web-app chain slug for swap links.
- Official Stock Token list as `TOKEN_REGISTRY` JSON (symbol, address, underlying_ticker, name, decimals, pool_address, pool_fee, proxy).
- Futures data vendor for ES/NQ/CL/GC/ZN (only BTC is wired). Without it, fair value is unknown for equity ETFs.
- Equities vendor for official closes/opens (`EquityPrintSource`); until then last_close is the token's own 16:00 mid.
- Embedding provider (`VOYAGE_API_KEY`; dimension 1024 in `packages/db/src/schema.ts`).
- Sign-in provider (Privy) issuing the same JWT; `/v1/auth/local` exists only in local mode.
- VAPID keys for push (`npx web-push generate-vapid-keys`); X API credentials and access tier for auto-posting (confirm the v2 create-post endpoint).
- ElevenLabs voice id for each brief language (`ELEVENLABS_VOICE_ID`); confirm `eleven_multilingual_v2` covers hi/es to your standard.
- Telegram: create the Mini App in BotFather (`/newapp`, URL = `<APP_URL>/tg`), set `TELEGRAM_MINIAPP_LINK`, run `pnpm telegram:setup`.
- Apple: App ID with Push Notifications, APNs auth key (.p8) → `APNS_*`, `APPLE_TEAM_ID`, bundle id; Live Activity widget needs iOS 16.2+. Native code has only been syntax-checked (`swiftc -parse`), never compiled in Xcode.
- Expo: `eas init` for `EAS_PROJECT_ID`, FCM credentials uploaded to EAS for Android pushes, `EXPO_ACCESS_TOKEN` if enhanced push security is on.
- Confirm the RSS URLs in `apps/worker/src/sources.ts` and the NYSE holiday list in `packages/core/src/market.ts`.
